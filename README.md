A multi-page React website for a local hair salon, built from real client requirements.

## Features
- Pages: Home, Services, About, Contact, and Gallery
- Services and pricing list
- Before and after gallery
- Responsive design

## Built with
- React
- Vite
- React Router
- styled-components

## Run it locally
```bash
npm install
npm run dev
```
